# Methods: conventions, algorithms, and why each certificate is sound

Read `WRITEUP.md` first for the result. This file is the level of detail needed to re-derive or re-implement it.

## 1. Conventions

**Tile.** Tile(1,1) drawn as a 14-gon with unit edges (13 corners plus one straight vertex). Vertices in `spectre.py`,
`SPECTRE`. Area 3 + 3 sqrt(3), about 8.196 (`A0` in the code).

**Supertiles.** Nine labels: Gamma, Delta, Theta, Lambda, Xi, Pi, Sigma, Phi, Psi. A level-n supertile has 8 children
(level n-1) at child indices 0..7, placed by `t_rules`; Gamma has no child 2. Child 7 is always a Gamma.
At level 0 a supertile is one spectre, except Gamma, which is a "mystic": two spectres.

**Shapes.** All non-Gamma labels have the same geometry at every level. So:

- `D`: children 0..6 are D, child 7 is G.
- `G`: children 0, 1, 3, 4, 5, 6 are D, child 7 is G.
- Tile counts: N_D(n+1) = 7 N_D(n) + N_G(n), N_G(n+1) = 6 N_D(n) + N_G(n), with N_D(0) = 1, N_G(0) = 2.
  Growth factor 4 + sqrt(15) = 7.873.

**Canonical tile order.** Tiles of a supertile are listed child by child in index order, recursively. All tile
indices in rule files and base paths use this order.

**Key points (quad).** Four points per supertile. At level 0 they are spectre vertices 3, 5, 7, 11. Child placements
at level n+1 and the level-n+1 quad are built from the level-n quad.

**Reflection.** Each level applies x -> -x. All tiles of a patch end up with the same handedness.

**Location syntax.** `pre(per)` with an optional trailing `b`. Letters are child indices read from the top level down:
`0(5)` = 0, 5, 5, 5, ... At level n the first n letters are used. If the word ends in a mystic, `b` selects its second
tile. Words are stored in a canonical form (primitive period, shortest prefix).

**State syntax.** `shape|entry|exit`, e.g. `D|(5)|0(5)`.

## 2. Exact arithmetic

Two independent representations are used.

- `core.py`: a point is a + b z + c z^2 + d z^3 with z = exp(i pi/6) and integers a, b, c, d. Rotation by 30 degrees
  and the reflection are 4x4 integer matrices (`ROT1`, `REFL`).
- `independent_check.py`: each coordinate is p + q sqrt(3) with rational p, q.

**Quad recurrence.** Stack the four key points into v_n in Z^16. Then v_{n+1} = M v_n for one fixed 16x16 integer
matrix M (built in `core.py` from the placement rules). The orbit {v_n} spans a 6-dimensional space
(`02_find_rule.py` computes the rank exactly).

**Relative position.** For two same-level supertiles A, B: T_A^{-1} T_B = (L, C v), where L is a 4x4 integer matrix
(rotation, no reflection) and C is a 4x16 integer matrix applied to the quad vector of their own level.

**Lemma (canonical key).** If C v_n = C' v_n for 16 consecutive n starting at n0, then for all n >= n0.
Proof: (C - C') vanishes on v_n0, M v_n0, ..., M^15 v_n0, which span the M-invariant cyclic subspace generated by
v_n0; every later v_n lies in it. Keys are the values at levels 2..17.

**Descent.** If A, B have relative position (L, C) and a, c are child indices, the children have relative position
(L_a^{-1} L L_c, L_a^{-1} (L tau_c + C M - tau_a)), where child j is placed by (L_j, tau_j v). This is `descend` in
`core.py`. Siblings a, c: (L_a^{-1} L_c, L_a^{-1} (tau_c - tau_a)).

## 3. Exhaustive search (`spectre.py: solve`)

For a supertile with children c_1..c_m, `feas[e]` is the set of exit tiles x such that a hierarchical Hamiltonian path
runs from e to x. Entries and exits are restricted to boundary tiles of the supertile.

- Enumerate Hamiltonian orders of the child adjacency graph.
- For each order, work backwards: R_i[y] = set of final exits reachable when child i is entered at y.
  R_i[y] = union over exits z of child i from y, and neighbours y' of z in child i+1, of R_{i+1}[y'].
- Exit sets are Python integers used as bitmasks. Suffixes of orders are memoised.

`build` reconstructs one explicit path. It is deterministic; the level-2 paths it returns for the 30 states are saved
in `results/base_paths_min30.json`.

## 4. The rule certificate (`core.py: prove`, `03_verify_rule.py`, `independent_check.py`)

**Statement.** For every state s in the rule and every level n >= 2 there is a hierarchical Hamiltonian path of the
level-n supertile of s's shape from tile(entry) to tile(exit).

**What is checked.**

(a) Base: at level 2 every state has such a path (search).
(b) Each production lists every child once; the first child's state has entry = tail(parent entry) and the last has
    exit = tail(parent exit); the first and last child indices are the heads; all child states are in the rule.
(c) Each junction: a triple (shape A, shape B, relative position k, exit location nu, entry location mu), meaning
    "tile(nu) of A shares an edge with tile(mu) of B".

**Junctions at all levels.** Let P(m) say: every triple in a set J holds when A and B are level-m supertiles.
- J is closed: each triple (k, a.nu', c.mu') maps to (descend(k, a, c), nu', mu'), also in J. Truth of the first at
  level m is exactly truth of the second at level m-1, because tile(a.nu') in A is tile(nu') in child a.
- P(2) is checked directly in exact arithmetic for every triple in J.
- Hence P(m) for all m >= 2.
`prove` builds J by following the chain until it meets a triple already seen.

**Induction on states.** Level n >= 3: concatenate the children's paths (level n-1 >= 2, valid by hypothesis) in the
production's order; consecutive ones join by P(n-1). Contiguity of all sub-supertiles is inherited.

## 5. Finding and minimising the rule (`02_find_rule.py`)

- Candidate locations: words in a family (prefix length <= PRE, period <= PER) whose tile is a boundary tile at
  levels 2, 3, 4.
- Candidate junction facts: pairs adjacent at level 3, then proven by `prove`.
- Candidate states: (entry, exit) feasible at levels 2, 3, 4.
- Greatest fixed point: drop states with no production into remaining states (`gfp`).
- Minimum closed rule: CP-SAT. Boolean x_s per state. For each state and compatible child order, a layered graph of
  (entry, exit) choices per step, pruned forwards and backwards. Constraints: x_s implies some order; a chosen order
  implies a first-layer node; a node implies a compatible node in the next layer and implies x of its state.
  Minimise the sum of x. The solution is re-checked by `gfp` and by both checkers.

## 6. Interior certificate (`09_interior.py`)

**Statement.** In a D supertile of level n >= 4, every tile of the grandchild at address 6,6 has all 14 edges shared
with tiles of that supertile.

**Definition.** (X, E): a supertile of shape X with an environment E, a set of (shape, relative position). It is
*surrounded* at level m if every edge of every tile of X is shared with a tile of X or of a member of E.

**Descent.** If every child a of X is surrounded by E_a, where E_a consists of siblings of a and children of members of
E at the exact descended positions, then X is surrounded by E. E_a is cut down to members that share an edge with the
child at level 2; a smaller environment only makes the claim stronger.

**Closure.** From the start pair the reachable set has 17 pairs, each with 6 members. Each is checked at level 2 in
exact arithmetic. Induction on the level as in section 4.

**Use.** With S_{n-2} = grandchild 6,6 of S_n: every edge-neighbour of a tile of S_{n-2} lies in S_n. So the ball of
radius k around a tile, in the tile adjacency graph, lies in S_{n0+2k}. The union of the chain is the whole tiling.

## 7. Locality: exact maximum at a level (`06_locality_limit.py`)

- Centroids and the curve order are built recursively in numpy (no Python tile lists), so level 8 fits in memory.
- Blocks of consecutive curve indices in a binary hierarchy, each with a bounding box.
- A pair of blocks (a < b) of size S is discarded if maxdist(boxes)^2 / ((b-a-1) S + 1) is below the best ratio so far.
  Otherwise it is split. Leaves (64 points) are evaluated exactly.
- The best-so-far is seeded from a sample of fixed gaps. Padding repeats the last point, which cannot raise the maximum.

## 8. Locality: bound at every level (`10_locality_bound.py`)

**Node.** (state A, state B, relative position, n_D, n_G). Claim: for every level m >= 2, every tile u on A's curve and v
on B's curve satisfy dist(u, v)^2 <= T x area x gap, with
gap = (tiles after u in A) + n_D N_D(m) + n_G N_G(m) + (tiles before v in B) + 1.

**Coverage.** Any pair of tiles on any state's curve at any level either lies inside one level-2 curve (checked
exactly, worst 5.64), or has a lowest common supertile of level >= 3 in some state q, with u and v in different
children. That is the root node (child state i, child state j, sibling position, shapes strictly between).
There are 770 roots.

**Settling a node.**
- *Bound.* dist <= |centre_A - centre_B| + r_A(m) + r_B(m) and gap >= 1 + n_D N_D(m) + n_G N_G(m).
  Centres are the mean of the four key points. If the resulting ratio is below T for every m, the node holds.
- *Split.* Otherwise check level 2 exactly (all tile pairs, exact gaps) and pass the claim to child nodes: u in A's
  step i, v in B's step j, with n' = (children of A after step i) + (7 n_D + 6 n_G, n_D + n_G) + (children of B
  before step j). Level m of the parent follows from level m-1 of the children.
- Nodes with n = (0, 0) are consecutive blocks. Their bound is useless, so they always split. They are keyed exactly
  and visited once; there are 72.

**Radii.** r_X(m) is exact for m <= 6 (enumeration). Above that, r_X(m) <= max over great-grandchildren of
(distance of its centre from the supertile's centre + r(m-3)). Three levels at a time keeps the overestimate near 1%.

**All levels.** Quantities are divided by lambda^m (lengths) or mu^m (counts), lambda^2 = mu = 4 + sqrt(15).
The bound is evaluated at every level from 2 to at least 45. Beyond that the normalised quantities are treated as
constant; over levels 45-57 they change by less than 4e-15. A factor 1 + 1e-9 is applied to every bound.

**Precision.** Relative positions are carried as exact integers: the 4x6 matrix of values at levels 2..7, advanced by
K -> L_a^{-1} (L tau_c + K S - tau_a), where S is the 6x6 integer shift matrix of the recurrence
(v_8 expressed in v_2..v_7; the coefficients are integers). Floating-point values at all levels are derived from
these and refreshed from the integers every 6 levels of depth.

**What this is and is not.** It is a computation in double precision without interval arithmetic, with one stated
assumption about levels above 45. It is strong evidence with tight controls. It is short of a formal proof.

**Controls.** T = 8.9 fails on a pair with ratio 8.94165 (the exact level-8 maximum). T = 8.97 fails at 8.97496
(the family's level-10 value). T = 8.97984 fails at level 19. T = 8.979841 succeeds with 1,218 nodes.

## 9. Markings (`13_self_drawing.py`, `14_markings.py`)

**Edges.** Edge j of a tile runs from vertex j to vertex j+1 of the 14-gon in `spectre.py`. All tiles of a level-4
patch are rotated copies of the base tile (none mirrored), so edge indices are comparable across tiles.

**Meeting table.** For every interior edge of the 4,401-tile patch, record (edge index on one tile, edge index on the
other). Any pair seen is a real adjacency in every tiling. The impossibility claims only use pairs that were seen.

**Truchet strands.** A marking is a perfect non-crossing matching of the 14 edges. Ports are (tile, edge). A strand
alternates "follow the arc inside the tile" and "cross the shared edge". Strands starting at the patch boundary are
open; arcs not on any open strand lie on closed loops.

**Minimum palette for a fixed curve.** Step i joins tile i to tile i+1 and has a list of shared edges. A choice c_i
picks one. Tile i's marking is determined by (c_{i-1}, c_i). For a set of allowed markings, feasibility is a forward
pass along the curve. Reverse deletion removes markings while the pass still succeeds. The exact model in CP-SAT has
one integer per step, one table constraint per tile, one Boolean per marking, and minimises the number of markings
used. A palette for a patch is a lower bound for any longer stretch of the same curve.

## 10. The art page (`15_art_page.py`, `art/tmpl.html`)

Each tile is stored as (x, y of vertex 0, rotation in units of 30 degrees, midpoint of the crossing edge to the next
tile), in curve order, with coordinates in hundredths. The page rebuilds the 14-gons from the base shape. The thread
is one smooth spline (uniform Catmull-Rom) through the centre of each tile and the middle of each border two
consecutive tiles share. See section 11. The marked tiles on the page follow the same rule: a tile's
marking is the pair of edges where that line enters and leaves it. This gives 32 markings, the same on 4,401 and
34,649 tiles. Choosing crossing edges to make the kit as small as possible gives 20 (section 9); the page shows the
32 that match the drawn line.
`ends[m]` lists where each of the 8 pieces of the level-m cluster ends along the curve; the build-up animation is a
function of time only, so the slider can scrub it.

## 11. Drawing the line inside the tiles (`17_drawing.py`)

The mathematics fixes the order of the tiles and nothing else. Three things are free: which shared edge the line
crosses, where on it, and what it does inside a tile. The rule used for the page:

1. **Pass through the centre of each tile.** This is the convention of Hilbert's own pictures, which join cell centres.
2. **Cross at the middle of the border the two tiles share.** Neighbouring spectres share a run of 1 to 4 edges. Take
   the middle edge of the run (for an even run, the middle edge nearer the line between centres) and cross at its midpoint.
3. **Join these points with a smooth spline.**

Measured on 4,401 tiles, with lengths in tile-edge units:

| Drawing rule | Self-crossings | Outside its two tiles | Clearance from itself | Reach | Length per tile |
|---|---|---|---|---|---|
| centres only | 0 | 0.15% | 1.62 | 2.44 | 3.06 |
| centres + palette crossing edge | 0 | 0 | 1.46 | 2.44 | 3.60 |
| centres + middle of the shared border | 0 | 0 | 1.72 | 2.44 | 3.07 |

Clearance is the smallest distance between two parts of the line at least 2 tiles apart along it. Reach is the largest
distance from any tile corner to the line. The chosen rule stays inside its tiles, keeps the widest clearance, and is
as short as the centres-only line. Reach is the same for all three: it is set by the tile's own arms.

A stronger principle that would fix the interior path completely, and is not implemented: the thickest ribbon. Take
the line whose thickened version is as wide as possible without touching itself or leaving its tiles.
